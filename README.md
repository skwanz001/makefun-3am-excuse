One line under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The wallet runs a sobriety test on its owner — its USB port doubles as a breathalyzer — and the punchline is that the owner cannot even spell "sleep".

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (113 characters, standard library only).
